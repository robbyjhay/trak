# 01 Origin

This directory preserves the historical starting point of the TRAK application.

Before TRAK was a Next.js application backed by a PostgreSQL database, it existed as a pair of frontend-only HTML/JS prototypes. These source documents defined the workflows, user roles, UI design, and features that would dictate all subsequent development.

## Documents

* **[original-product-vision.md](./original-product-vision.md)**: The most important historical document. Answers the question: "What was TRAK originally supposed to be?"
* **[prototype-1-analysis.md](./prototype-1-analysis.md)**: A breakdown of the first iteration of the prototype (`Trakprototype.txt`).
* **[prototype-2-analysis.md](./prototype-2-analysis.md)**: A breakdown of the second, expanded iteration of the prototype (`Trakprototype (3).txt`).
* **[prototype-comparison.md](./prototype-comparison.md)**: A direct comparison showing how the concept evolved between the two prototypes before actual backend development began.
