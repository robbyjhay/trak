2. USER ROLES AND PRIMARY FLOWS
--------------------------------------------------------------------------------

2.1 Unauthenticated visitor
  Paths: /login, /rsvp/[token], static assets
  Missing: Forgot password, help contact, status page

2.2 First-time member (invite / Head-created)
  Flow: Receive credentials → Login → Forced set password → Profile → Dashboard
  Gaps:
    - Credentials delivered only via Head toast (no email/SMS)
    - Skip allowed (must disable in production)
    - No onboarding checklist (photo, phone, designation)

2.3 Member daily work
  Flow: Dashboard KPIs → New Activity → Pending → Daily log → Complete → Report
  Gaps:
    - Budget fields
    - Loading skeletons inconsistent
    - Error on submit not always blocking double-submit
    - Offline draft autosave missing
    - Attachment failures unclear

2.4 Head oversight
  Flow: Admin Portal → Team performance → Unit activities → Delegate → Comment
        → Team profiles → Responsibilities → Broadcast
  Gaps:
    - Hardcoded greeting
    - Fake personnel KPI
    - Hide/unhide missing
    - No audit of admin actions
    - Cannot deactivate member accounts

2.5 Public attendee RSVP
  Flow: Open link → Form → Submit → Success
  Gaps:
    - Token not cryptographically verified
    - No rate limit / CAPTCHA
    - No duplicate name detection
    - Success state no receipt/reference number
    - Invalid/expired activity states (completed/missed) not blocked server-side

2.6 Messaging
  Flow: Messages → Community / DM / Broadcast
  Gaps:
    - Search non-functional
    - Mentions/replies missing
    - No read receipts
    - No pagination (all messages in bootstrap)
    - Simulated calls confuse users

4. REQUIRED UX IMPROVEMENTS (PRODUCTION)
--------------------------------------------------------------------------------

UX01 [CRITICAL] Global error boundary
  Add app/error.tsx and route-level error.tsx with retry + support contact.

UX02 [CRITICAL] Global loading UI
  Add loading.tsx for shell routes; skeleton components already exist — use them.

UX03 [CRITICAL] Mutation pending states
  Disable primary buttons while API in flight; prevent double submit on logs.

UX04 [HIGH] Offline banner
  navigator.onLine + failed fetch → sticky "You're offline" banner.

UX05 [HIGH] Empty states with CTAs
  - No activities: "Create your first activity"
  - No messages: "Start a conversation"
  - No notifications: "You're all caught up"
  - No responsibilities (edge): Head prompt to add

UX06 [HIGH] Form validation messages
  Inline field errors (not only toast) for new activity, profile, add member,
  set password, RSVP.

UX07 [HIGH] Confirm destructive actions
  Wipe community: type "WIPE" to confirm.
  Future delete activity: confirm modal.

UX08 [HIGH] Settings complete
  Sections: Account (password), Notifications (toggles), Sessions, About.

UX09 [HIGH] Accessible modals
  Focus trap, Escape to close, aria-modal, return focus.

UX10 [HIGH] Live region for toasts
  role="status" aria-live="polite" on Toast.

UX11 [MEDIUM] Time-of-day greeting
  Good morning/afternoon/evening + first name for Head and Member.

UX12 [MEDIUM] Call UI honesty
  If WebRTC not shipping: rename to "Log a phone call" or remove Call button.

UX13 [MEDIUM] RSVP success reference
  Show confirmation code; optional SMS/email receipt later.

UX14 [MEDIUM] Activity filters
  Port All time / This week / This month + Show hidden for Head.

UX15 [MEDIUM] Keyboard shortcuts
  Optional: n for new activity, / focus search.

UX16 [LOW] Reduced motion
  Respect prefers-reduced-motion for call animations / ping.
